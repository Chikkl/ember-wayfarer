# Съёмка этапов

Как получить скриншоты и видео игры на любом этапе, чтобы сравнивать «было и стало».

## Этапы

Этап — это git-тег на последнем коммите этапа. Для прототипа имена `proto-N`.

| Тег | Коммит | Что в игре |
| --- | --- | --- |
| `proto-1` | 33d9ab1 | Первый играбельный прототип: ходьба, выносливость и усталость, работа удержанием, отдых у костра |
| `proto-2` | 6d503ae | После первого плейтеста: у костра отдых заметно быстрее, чем в лесу |

Новый тег ставим, когда игра заметно изменилась:

```bash
git tag -a proto-3 <коммит> -m "Prototype 3: <что изменилось>"
git push origin proto-3
```

## Как снять этап

Мир строится с фиксированными зёрнами, поэтому на одном теге он всегда одинаковый. Снимаем из отдельного worktree, чтобы не трогать рабочую копию:

```bash
GODOT="путь/к/godot"
CAPTURES="путь/к/ember-wayfarer/captures"

git worktree add ../ember-wayfarer-proto-1 proto-1
cd ../ember-wayfarer-proto-1
"$GODOT" --headless --path . --import
"$GODOT" --path . --write-movie "$CAPTURES/2026-10-29_proto-1_rest.avi"
cd -
git worktree remove ../ember-wayfarer-proto-1
```

- Во время записи можно играть руками. Запись останавливаем крестиком окна. Ctrl+C и F8 не нажимаем: AVI может испортиться.
- Длину можно задать заранее: `--quit-after 900` — это 900 кадров, при 60 кадрах в секунду 15 секунд.
- Окно для вертикального видео: `--resolution 608x1080`.
- Movie Maker пишет не в реальном времени. Если игра в записи идёт заметно быстрее обычного и играть руками неудобно, снимай через OBS.

AVI получается большим. Переводим в mp4 и берём кадр для скриншота:

```bash
ffmpeg -i rest.avi -c:v libx264 -crf 18 -pix_fmt yuv420p rest.mp4
ffmpeg -ss 5 -i rest.mp4 -frames:v 1 rest.png
```

## Имена и хранение

Имя файла: `<дата>_<тег>_<что снято>`, например `2026-10-29_proto-2_rest-at-fire.mp4`.

Видео и скриншоты в git не кладём, иначе репозиторий навсегда станет тяжёлым. Папка `captures/` в корне репозитория скрыта через `.gitignore`. Копию храним вне компьютера, например на Google Диске.

## Чтобы старые этапы запускались

- Храним Godot 4.7.2: новая версия может не открыть старый тег как есть.
- Любая случайность в игре задаётся зерном, как у травы и деревьев. Иначе один и тот же тег будет выглядеть по-разному.
