# Глоссарий

Единые термины проекта. Если слово используется в документах или коде, оно значит ровно то, что написано здесь.

| Термин | В коде | Значение |
| --- | --- | --- |
| Клетка | `tile` | Один тайл мира, единица расстояния в документах |
| Выносливость | `stamina` | Быстрая шкала: тратится на действия, восстанавливается за секунды |
| Усталость | `fatigue` | Медленный долг, который копится от потраченной выносливости и уменьшает её максимум |
| Истощение | `exhausted` | Короткое состояние при нуле выносливости: нельзя работать, ходьба медленнее |
| Отдых | `rest` | Персонаж сидит, снимает усталость и восполняет выносливость; комфорт ускоряет и то и другое |
| Лагерь | `camp` | Зона радиусом `camp_radius` вокруг костра |
| Комфорт | `comfort` | Общий показатель лагеря: сумма лучших предметов из каждой группы |
| Группа комфорта | `comfort_group` | Категория предметов (огонь, сон, сиденье, укрытие); из группы учитывается один лучший предмет |
| Поселенец | `settler` | Человек, пришедший к лагерю, но ещё не принятый (этап «Колония») |
| Житель | `villager` | Принятый поселенец, живёт в лагере и работает |
| Доверие | `trust` | Отношение жителя к игроку; определяет, что ему можно поручить |
| Узел | `tree_node` | Элемент дерева развития |
| Опыт | `xp` | Фиксированная награда за действие; копится до следующего уровня |
| Уровень | `level` | Уровень персонажа; каждый новый даёт очко развития |
| Очко развития | `tree_point` | Валюта дерева рецептов: одно очко открывает один узел |
| Дерево рецептов | `recipe_tree` | Дерево развития, которое отвечает за то, что игрок умеет делать |
| Практика | `practice` | Опыт крафта конкретного предмета; повышает его качество |
| Линия | `craft_line` | Группа похожих предметов (например, топоры); практика предмета немного переходит на всю линию |
| Качество | `quality` | Насколько хорошо сделана вещь; зависит от практики |
| Шалаш | `hut` | Первое жилище под крышей; открывается последним узлом шага 1 |
| Подбор | `pickup` | Взять предмет с земли; мгновенно и без выносливости |
| Работа | `work` | Действие над объектом (рвать, рубить); стоит выносливости |
| Объект ресурса | `resource_node` | То, из чего добывают: куст, дерево, ветка на земле |
| Добыча | `drop` | Предметы, которые выпадают из объекта ресурса |
| Восстановление | `respawn` | Возвращение истощённого объекта ресурса через `respawn` секунд: ветка или камень появляются в своей зоне, куст отрастает, на пне вырастает дерево |
| Вес | `weight` | Сколько весит предмет; груз игрока равен сумме весов |
| Перегруз | `overload` | Груз выше `carry_limit`: ходьба медленнее, выше потолка подобрать нельзя |
| Кучка | `ground_item` | Предметы одного вида на земле: выпавшая добыча или выброшенная стопка |
| Корзина | `basket` | Плетёный склад в лагере: ячейки со стопками, без ограничения по весу |
| Рецепт | `recipe` | Что нужно, чтобы сделать предмет или постройку: материалы, инструменты, время, опыт |
| Инструмент рецепта | `tools` | Предмет, который нужен для рецепта, но не тратится |
| Рубило | `chopper` | Первое каменное орудие: им обрабатывают палку, а потом оно становится частью топора |
| Постройка | `building` | Результат рецепта, который ставится в мир, а не попадает в инвентарь |
| Режим постройки | `build_mode` | Режим, в котором игрок ставит постройку по превью или разбирает её |
| Разбор | `dismantle` | Убрать постройку и вернуть долю материалов `dismantle_refund` |
| Пень | `stump` | Остаётся от срубленного дерева; выкорчеванный пень больше не даёт дерева |
