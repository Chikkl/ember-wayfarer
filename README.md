# Ember Wayfarer

Рабочее название. Колония с огромным деревом развития: просыпаешься с пустыми руками у горящего костра, обустраиваешь лагерь, а со временем на огонёк к тебе приходят странники. 2.5D, крафт, жители с доверием и навыками, ARPG-бой со способностями.

**Движок:** Godot 4 (предварительно) · **Статус:** проектирование ядра

## Структура

```
docs/
  gdd.md              дизайн-документ и оглавление всех спецификаций
  systems/            спецификации систем
  decisions.md        журнал решений: что решили и почему
  glossary.md         единые термины
data/                 игровые параметры и таблицы (JSON, CSV), их читает игра
CLAUDE.md             контекст для работы с Claude
```

## Как устроена документация

- **Оглавление:** [docs/gdd.md](docs/gdd.md). С него стоит начинать.
- Подробно описываем только то, что делаем в ближайшем шаге. Остальное держим в общих чертах.
- Все числа живут в `data/`, а не в коде, чтобы баланс правился без изменения кода.
- Каждое заметное решение записывается в [журнал решений](docs/decisions.md).
