# Ember Wayfarer

Рабочее название. Колония с огромным деревом развития: просыпаешься с пустыми руками у горящего костра, обустраиваешь лагерь, а со временем на огонёк к тебе приходят странники. 2.5D, крафт, жители с доверием и навыками, ARPG-бой со способностями.

**Движок:** Godot 4.7 · **Статус:** прототип шага 1

## Структура

```
docs/
  gdd.md              дизайн-документ и оглавление всех спецификаций
  systems/            спецификации систем
  decisions.md        журнал решений: что решили и почему
  glossary.md         единые термины
data/                 игровые параметры и таблицы (JSON, CSV), их читает игра
src/                  код и сцены игры (GDScript)
tests/                тесты GUT
addons/gut/           GUT 9.7.1, фреймворк тестов (сторонний код)
tools/check.sh        проверки перед коммитом: тесты, gdlint, gdformat
project.godot         проект Godot
CLAUDE.md             контекст для работы с Claude
```

## Как запустить

Открыть `project.godot` в Godot 4.7 и нажать F5.

Управление в прототипе: WASD или стрелки — ходить, R — сесть отдохнуть или встать, E (удерживать) — подобрать, рвать или рубить ближайший объект, левый или правый клик по ячейке инвентаря — выбросить один предмет или всю стопку, C — меню крафта, B — разбор построек, T — дерево рецептов. Каменный топор теперь делается в крафте.

## Проверки перед коммитом

Нужны Godot 4.7 и [gdtoolkit](https://github.com/Scony/godot-gdscript-toolkit) (`pip install gdtoolkit`). В Git Bash или на Linux:

```
GODOT="путь/к/godot" tools/check.sh
```

Скрипт импортирует проект, прогоняет тесты GUT, `gdlint` и `gdformat --check`. Без `GODOT` берётся `godot` из `PATH`.

## Как устроена документация

- **Оглавление:** [docs/gdd.md](docs/gdd.md). С него стоит начинать.
- Подробно описываем только то, что делаем в ближайшем шаге. Остальное держим в общих чертах.
- Все числа живут в `data/`, а не в коде, чтобы баланс правился без изменения кода.
- Каждое заметное решение записывается в [журнал решений](docs/decisions.md).
